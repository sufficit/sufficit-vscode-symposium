# AHP operational telemetry

Status: **Completed**
Date: 2026-08-09

## Activity

Implemented bounded, OTLP-shaped operational measurements outside AHP durable
state and replay.

## Delivered

- allowlisted lifecycle, reconnect, replay, projection, backpressure and
  rejection metric names;
- consent, enablement and sampling gates before enqueue;
- bounded queues and bounded allowlisted labels;
- exclusion of prompts, tool payloads, file content and credentials;
- non-blocking exporter with failure isolation;
- capability advertisement only when consent and an exporter are active.

## Validation

Tests prove disabled-mode silence, label redaction, queue behavior, exporter
failure isolation and absence from serialized runtime state.

## Outcome

Operational observability is available without becoming a reconstruction
dependency or a path for durable user-controlled secrets.
