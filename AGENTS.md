# Sufficit Symposium agent instructions

Use Node.js 22 and follow the [development setup](README.md#development).
Run `npm run verify` for code changes. Use the [testing guide](docs/maintainers/testing.md)
to choose more focused checks and the [release procedure](docs/maintainers/release.md)
for authorized packaging or publication.

- [Architecture](ARCHITECTURE.md) and [maintainer documentation](docs/README.md)
  describe the extension host, webview and agent backends.
- [Session recovery](docs/guides/session-recovery.md) and
  [session history](docs/maintainers/session-history.md) cover continuity.
- For a mission managed by Fleet, see [Fleet guidance](FLEET.md).
